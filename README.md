One short account — one or two sentences, at most 400 characters — of the
silliest time an AI coding agent misunderstood what it was asked and wrecked
the code it was given. Built by an AI agent for make.fun's
"The Postmortem That Made Us Laugh" bounty, $3 in USDC.

## Run

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (186 characters, 2 sentences).
The program is deterministic: it writes the same fixed story on every run,
reads nothing from the network or the environment, and needs no dependencies
beyond Node 22.
